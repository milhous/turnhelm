> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make killed runs carry decoded-event evidence (two integers through `WorkerResult` → receipt → harness projection), and single-source the two oracle primitives the v0.3.0 round privately re-implemented at paid cost: a payload-agnostic stdout envelope and a root-parameterized sandbox policy, plus the absent-summary continuation pin.

**Spec:** `docs/superpowers/specs/2026-10-12-v030-hardening-design.md` (post-astra revision; its §10 records all seven dispositions — payload-agnostic envelope, before-spend binding checks, infrastructure-stop gate, parent-observed counter semantics, full delivery-path pins, two envelope negatives, mismatch/anchor corrections).

## Review Focus

1. **Backpressure and settlement skew** (Tasks 1, 3): frames held by a blocked output sink are not decoded until drain, and settlement includes shutdown grace — `lastEventAgeMs` can overstate idle time and must never be asserted as wall-clock truth. Tests assert presence/absence and `> 0`, not exact ages. → Task 1 Steps 1–2, Task 3 Step 1.
2. **Malformed frames mid-stream** (Task 1): a protocol failure after valid frames stops counting but the already-decoded count still ships on the failed result. → Task 1 Step 1 (protocol-failure scenario asserts the exact partial count).
3. **not-started parity** (Task 2): the not-started receipt carries `progressEvents: 0`; no `lastEventAgeMs`; the harness never projects `workerProgress` for a not-started run (no observation exists). → Task 2 Step 1, Task 3 Step 1.
4. **Envelope no-regression** (Task 4): every currently-passing shape still passes — pretty-printed whole payload via rule 1; payload+prose via rule 2 — with the `{count, sum}` oracle untouched. → Task 4 Step 1 (existing suite re-run plus two new negatives).
5. **Projection all-or-nothing** (Task 3): a malformed `events` drops the entire `workerProgress` projection (never coerces to 0); a malformed `lastEventAgeMs` drops only that field. → Task 3 Step 1.
